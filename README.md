# desercion-estudiantil-analisis
Análisis exploratorio y modelo predictivo sobre deserción estudiantil y éxito académico (Agosto 2026) utilizando un dataset de +4.400 registros para identificar factores de retención.
# Predecir la Deserción Estudiantil y el Éxito Académico (Agosto 2026) 🎓📈

### 🎯 Objetivo del Proyecto
Este proyecto desarrolla un análisis exploratorio de datos (EDA) detallado a partir de un universo de más de 4.400 estudiantes de educación superior. El propósito fundamental es identificar de forma analítica los factores socioeconómicos y académicos asociados a la deserción temprana para estructurar estrategias preventivas de retención institucional.

### 🛠️ Tecnologías y Herramientas Utilizadas
- **SQL / Python (Pandas):** Limpieza, normalización y transformación de las variables operativas de la cohorte estudiantil.
- **Visualización de Datos:** Construcción de reportes analíticos avanzados empleando segmentación demográfica y análisis de proporciones.

### 📊 El Dataset
El análisis se ejecutó sobre una base consolidada de **4.424 registros de estudiantes**, evaluando dimensiones clave como género, rendimiento académico previo, estado de matriculación (Graduate, Dropout, Enrolled) y asignación de soporte financiero (becas).

### 💡 Nota Metodológica e Insights Clave
- **El Impacto Crítico de las Becas:** Los datos reflejan una fuerte correlación entre contar con una beca y presentar una menor tasa de abandono. El análisis demuestra que el soporte financiero reduce la deserción universitaria a menos del 10%.
- **Sesgo de Selección vs. Causalidad:** Se destaca que la correlación no implica causalidad directa; la baja deserción en estudiantes becados puede estar asociada al desempeño académico previo exigido para mantener el beneficio, requiriendo análisis complementarios de selección.
- **Estrategia Recomendada:** Focalizar los esfuerzos de tutorías y acompañamiento casi exclusivamente en aquellos alumnos sin soporte financiero o con caídas marcadas en los indicadores de rendimiento intermedio.

### 📁 Estructura de este Repositorio
- `/scripts`: Hojas de código y consultas estructuradas para el procesamiento de los 4.424 estudiantes.
- `/data`: Diccionario de variables del dataset analizado (datos anonimizados).
